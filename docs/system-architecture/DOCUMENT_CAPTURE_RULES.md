# Document capture rules register

This register inventories every deterministic extraction, validation, warning, and masking rule used by document capture in:

- `src/Api/DocumentCapture/Parsing/DocumentTextFieldParser.cs`
- `src/Api/DocumentCapture/Parsing/DateAndAmountParser.cs`
- `src/Api/DocumentCapture/Parsing/BankFieldParser.cs`
- `src/Api/DocumentCapture/DocumentCaptureWarningCodes.cs`
- `src/Api/DocumentCapture/DocumentCaptureMasking.cs`

## Current `RulesVersion`

- **`RulesVersion`:** `rules-3`
- **`ProviderVersion` (local OCR):** `ocr-1+d5de5df3+20b69451+rules-3` (`CaptureWorkerModels.Version + "+" + DocumentTextFieldParser.RulesVersion`, must stay ≤ 100 characters)

## How to change a rule

1. Edit the affected row in the table below (or add a new row with the next unused two-digit ID; never reuse a retired ID).
2. Bump `DocumentTextFieldParser.RulesVersion` (e.g. `rules-1` → `rules-2`) and update **Current `RulesVersion`** above.
3. Add a line to the **Change log** section at the bottom of this file.
4. Add or update unit tests tagged with `[Trait("Rule", "<ID>")]` using invented test data only, and verify the register consistency test passes.
5. Run `./scripts/capture-benchmark.sh` locally with the OCR models and record the resulting markdown row in the **Benchmark** section below.

## ID conventions

- `V-` vendor and customer (party name)
- `N-` document number (`vendorInvoiceNo` / `sourceInvoiceNo`)
- `D-` dates (`date`, `dueDate`)
- `T-` totals, amounts, and tax (`sourceTotals`)
- `L-` line items (`lines`)
- `P-` payment hints (`paymentHints`)
- `C-` currency (`currency`)
- `B-` bank details (`bank` kind)
- `A-` assistant attachment fields (`assistant-attachment` kind)
- `G-` general parser bounds, sanitization, and deadline
- `W-` warning codes and sanitization
- `S-` sensitive-data masking
- `M-` party matching (vendor and customer matching, aliases, and archived handling)
- `AI-` optional field mapper guards (`mapper-contract-1`): source-text, arithmetic, disagreement, schema and failure guards between a mapper and storage. The brief's names `G-AI-01` to `G-AI-05` are `AI-01` to `AI-05` here.

IDs are two digits (`V-01`), stable, and never reused. A retired rule keeps its row with status `retired`.
